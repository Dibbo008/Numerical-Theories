# Numerical-Theories

A collection of **Numerical Methods implementations in C++** covering some of the most important numerical techniques used for solving equations, systems of equations, interpolation, regression, matrix problems, and numerical integration.

This repository is created for learning, practice, and academic use.

---

## 📚 Topics Covered

| Topic | Methods |
|---|---|
| Root Finding | Bisection, False-Position |
| Linear Systems | Gauss Elimination, Gauss-Jordan |
| Matrix Methods | LU Decomposition, Matrix Inversion |
| Interpolation | Newton's Forward, Newton's Backward |
| Root Finding | Newton-Raphson, Secant |
| Regression | Linear, Power, Polynomial |
| Numerical Integration | Simpson's 1/3, Simpson's 3/8 |
| Differential Equations | Runge-Kutta 4th Order |
